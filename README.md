# ShopEasy – Online Shopping Website

ShopEasy is a simple and responsive online shopping website built using **HTML and CSS**. It features a clean user interface where users can explore different products, view their prices, and navigate through different sections of the website.

## Features

- **Responsive Navigation Bar:** Easy navigation between Home, Products, About, and Contact sections.
- **Hero Section:** Welcome message with a Shop Now button.
- **Product Section:** Displays four products with images, names, and prices.
- **Hover Effects:** Interactive hover animations on product cards and buttons.
- **About Section:** Provides a brief description of the store.
- **Contact Section:** Displays email and phone contact information.
- **Responsive Design:** Adapts to different screen sizes, including desktops, tablets, and mobile devices.

## Technologies Used

- **HTML5** – For website structure.
- **CSS3** – For styling, layout, animations, and responsive design.
- **Google/Unsplash Images** – For product images hosted by Unsplash.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code or any code editor.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in your web browser.
5. Alternatively, use the **Live Server** extension in VS Code to run the website.
